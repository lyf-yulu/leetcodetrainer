设置

AI 配置写在项目根目录的 config.json，key 只留在后端，不进浏览器。 改完需重启 node server.mjs。 

{
  "baseUrl": "https://api.deepseek.com/v1",
  "model": "deepseek-chat",
  "apiKey": "sk-...",
  "pyodideVersion": "v0.28.3"
}

任何 OpenAI 兼容服务都可以：DeepSeek、阿里百炼、OpenRouter、本地 vLLM 等。 baseUrl 填到 /v1 为止，程序会自己接 /chat/completions。
